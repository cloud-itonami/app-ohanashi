# etzhayyim-project-ohanashi Project Plan (MVP)

## 1. 背景と目的

`etzhayyim-project-ohanashi` は、電話でおじいちゃんおばあちゃんが AI に相談できるサービスを提供する。
主な公開ドメインは `https://ohanashi.etzhayyim.com`。

MVP のゴール:
- スマホ操作が苦手でも電話だけで利用できる
- 相談内容に応じた安全な回答と次アクション案内を行う
- 必要時は人間オペレーターへ確実にエスカレーションする
- 家族/介護者へ要約通知を提供する

## 2. MVP スコープ

### In Scope
- 音声通話での AI 対話（24時間）
- 相談カテゴリ: 生活一般、行政手続き案内、詐欺注意、雑談、健康一般情報
- 高リスク発話検知（急病/自傷/詐欺疑い）
- セッション終了後の要約生成
- 家族向け通知（SMS/メールのいずれか1系統）
- 家族向け Web ポータルの最小機能（同意、通知先設定、履歴閲覧）

### Out of Scope (MVP)
- 医療診断、法的助言の確定判断
- マルチ言語本番対応（MVP は日本語優先）
- 発信業務の完全自動化（コールセンター相当）

## 3. 非機能要件

- 可用性: 月間 99.9% 以上（MVP 目標）
- 応答性能: 対話ターン遅延 p95 2.0 秒以下
- セキュリティ: すべての監査ログ保存、PII 最小収集
- 監査性: 通話セッション単位で判定根拠・エスカレーション理由を追跡可能

## 4. フェーズ計画

### Phase 0: 設計確定（2026-02-25 〜 2026-03-05）
- 音声対話フロー定義
- エスカレーション運用設計
- 個人情報同意/通知ポリシー決定

### Phase 1: MVP 実装（2026-03-06 〜 2026-04-05）
- 電話ゲートウェイ連携
- voice orchestrator 実装
- family portal 最小版実装
- 要約通知実装

### Phase 2: 実証運用（2026-04-06 〜 2026-04-30）
- 20〜50 名で PoC
- 誤検知/未検知分析
- UX と会話設計を改善

### Phase 3: 本番拡張（2026-05-01 〜）
- 運用時間/オペレーター体制拡張
- 方言/話速適応チューニング
- RAG データソース拡張

## 5. KPI

- 初回通話完了率
- 再利用率（7日・30日）
- 危険検知 Recall / Precision
- 人間転送の適正率
- 家族通知の既読率

## 6. リスクと対策

- 誤検知が多い: しきい値 + ルール + human-in-the-loop で段階判定
- 医療/法律の誤案内: 明示ディスクレーマー + 禁止応答ポリシー
- 個人情報過収集: 保存期間を短くし、目的外利用を禁止
- 運用負荷集中: 営業時間外は callback queue を標準運用
